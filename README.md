# WD_FUTSAL (웹 버전 Ver.0.21.12 — 정식 출시 전이라 1.0 미만으로 표기)

신청 → 주장·순번 → 드래프트와 채팅 → 교환 → 공지 이미지 → 경기 기록까지 한 앱에서 진행해요.
config.js에는 wd-futsal Firebase 설정이 이미 들어 있어요. 운영진 비밀번호(adminPin)만 바꿔서 쓰면 돼요.

## 버전 규칙

- 정식 출시 전에는 0.x로 표기해요.
- 같은 버전 안에서 고칠 때마다 0.21.1 → 0.21.2 → 0.21.3처럼 끝자리를 올려요.
- "버전업" 요청이 있을 때 0.22처럼 가운데 자리를 올려요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀과 디자인 |
| `app.js` | 앱 기능 전체 |
| `config.js` | **Firebase 설정, 운영진 비밀번호, 조끼 색 목록, 기본값** (여기만 고치면 돼요) |
| `assets/` | 엠블럼, 앱 아이콘 |
| `firestore.rules` | Firebase 보안 규칙 (콘솔에 붙여넣기) |
| `manifest.webmanifest`, `sw.js` | 홈 화면에 앱처럼 설치하기 위한 파일 |

## 1. Firebase 프로젝트 만들기 (약 5분)

1. https://console.firebase.google.com 접속 → **프로젝트 추가** → 이름 입력(예: `wd-futsal`) → Google 애널리틱스는 꺼도 돼요.
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법** 탭에서 **익명**을 사용 설정으로 저장해요.
3. **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작
   - 만든 뒤 **규칙** 탭에 `firestore.rules` 내용을 붙여넣고 **게시**해요.
4. 프로젝트 개요 옆 ⚙ **프로젝트 설정 → 일반 → 내 앱**에서 웹 아이콘(`</>`) 클릭 → 앱 이름 입력 → 등록
   - 화면에 나오는 `firebaseConfig = { ... }` 값 6개를 `config.js`의 `firebase` 부분에 그대로 옮겨요.
5. `config.js`의 `adminPin`을 원하는 운영진 비밀번호로 바꿔요.

## 2. GitHub Pages에 올리기

1. GitHub에 새 저장소를 만들고(예: `wd-futsal`) 이 폴더의 파일을 모두 올려요.
2. 저장소 **Settings → Pages → Branch: main / (root) → Save**
3. 1~2분 뒤 `https://아이디.github.io/wd-futsal/` 로 접속해요.
4. Firebase 콘솔 **Authentication → 설정 → 승인된 도메인**에 `아이디.github.io` 를 추가해요.

## 3. 멤버들에게 공유

- 링크를 단톡방에 공유하면 누구나 열 수 있어요.
- 안드로이드 크롬: 메뉴 → **홈 화면에 추가** / 아이폰 사파리: 공유 → **홈 화면에 추가** 하면 앱처럼 아이콘이 생겨요.
- 운영진과 기록 담당자에게만 운영진 비밀번호를 알려 주세요. (오른쪽 위 운영모드 버튼)

## 사용 방식

- **일반회원**: 링크를 열면 별도 선택 없이 바로 들어와요. 하단 메뉴는 홈, 일정, 경기결과이고 설정은 오른쪽 위 ⚙ 버튼에 있어요.
  - 홈: MATCH REVIEW(지난 경기)와 NEXT MATCH(다음 경기). 휴대폰에서는 스크롤 없이 한 화면에 보이고, 신청 기간에는 "신청하기" 버튼이 하단 메뉴 바로 위에 고정돼요.
  - 일정: 달력에서 경기 있는 날이 색으로 표시되고(초록: 신청 중, 파랑: 경기, 회색: 종료), 날짜를 누르면 아래에 세부 일정이 나와요.
  - 경기결과: 가장 최근 경기부터 바로 보여요. 위쪽 좌우 버튼이나 휴대폰 스와이프로 이전·이후 경기로 넘겨요.
- **운영진**: 오른쪽 위 "운영모드" → 비밀번호. 메뉴는 4개예요.
  - **일정**: 달력(한 달 경기를 크게 보고, 날짜를 누르면 오른쪽에서 회차·시간·장소·정원·신청 기간을 바로 수정하고 예약자·당번·주차로 이동) / 목록(표로 한꺼번에 수정) / 월간 일정표(공지 이미지). 빈 날짜를 누르면 그 날 경기를 추가해요.
  - 경기 메뉴 위쪽에 선택한 경기의 날짜·장소·상태와 이전/이후 버튼, 그리고 신청 → 주장 → 드래프트 → 밸런스 → 팀 확정 → 경기 → 결과 단계 그림이 고정돼요. 단계를 누르면 그 단계 화면으로 바로 가요.
  - **경기**: 선택한 경기의 단계별 화면. 맨 아래 경기 도구에서 당번 지정, 주차 관리, 기록 붙여넣기를 열어요.
  - **회원**: 명단, 운영진(0순위) 표시, 로그인 초기화, 연락처
  - **설정**: 휘슬, 샘플 데이터 등
- **주장**: 운영진이 경기 메뉴의 주장 단계에서 회원을 주장으로 지정하면, 그 회원이 로그인할 때 팝업이 뜨고 화면 위 노란 띠와 하단 "팀 선정" 메뉴로 드래프트에 들어가요. (예전 설명) 운영진이 주장 단계에서 만드는 **주장 링크**로 들어와요. 링크를 열면 그 주장 이름으로 드래프트 화면에 바로 참여하고, 하단에 드래프트 탭이 추가돼요. 주장을 바꾸면 이전 링크는 쓸 수 없게 돼요.

## 화면 방식

- **PC(마우스로 쓰는 넓은 화면)**: 브라우저 창 전체를 써요. 메뉴는 왼쪽 세로 메뉴로 바뀌고, 홈, 결과 상세, 기록, 드래프트(채팅은 오른쪽), 경기 기록, 공지 화면이 두 칸으로 나뉘어 보여요.
- **스마트폰, 태블릿**: 세로 화면이고 메뉴는 아래에 있어요. 두 손가락 확대·축소는 막아 두었고, 드래프트 방은 스크롤 없이 한 화면에 명단, 테이블, 채팅 입력창이 모두 들어가요.

## 시뮬레이션(연습 데이터)

운영모드 → 설정 → 시뮬레이션에서 신청접수, 주장지정, 드래프트, 팀원조정, 경기모드 단계의 가상 경기를 실제 회원 명단으로 만들 수 있어요. 만든 뒤 바로 그 단계 화면으로 이동하고, "연습 데이터 모두 지우기"로 가상 경기와 그 신청·드래프트·채팅·경기 기록을 한 번에 지워요.

## 화면 이동

화면 맨 위에서 아래로 끌어내렸다 놓으면 새로고침돼요(홈 화면에 추가한 앱에서도 동작해요).

휴대폰·태블릿에서는 하단 메뉴를 눌러도 되고, 화면을 좌우로 밀어서 옆 메뉴로 이동할 수도 있어요(가운데 경기모드 버튼은 제외). 경기결과 화면에서는 좌우로 밀면 이전·이후 경기로 넘어가고, 더 넘길 경기가 없으면 옆 메뉴로 이동해요.

## 드래프트 진행

자기 차례인 주장이 명단에서 선수를 누르고 "선택 완료"를 누르면 바로 다음 주장 차례로 넘어가요. 잘못 골랐으면 내 팀 카드에서 방금 뽑은 선수(✕ 표시)를 눌러 취소할 수 있어요(다음 주장이 선택을 완료하기 전까지). 운영진은 언제든 "되돌리기"를 쓸 수 있어요.

- **경기모드 · 직접 설정**: 경기모드 위쪽에서 "✏️ 직접 설정"을 고르면 일정 없이도 팀 수(2~4팀)·팀 색·경기 수·시간을 정해 경기를 진행하고, 순위표와 경기별 결과를 정리·복사할 수 있어요(이 기기에만 저장).
- **운영모드 비밀번호 변경**: 운영모드 → 설정에서 바꿔요. 바꾼 번호는 모든 운영진에게 적용돼요.
- **드래프트 참관자**: 경기 → 주장지정 단계 아래에서 운영진이 참관자를 지정하면, 그 회원에게만 하단 "드래프트 참관" 메뉴가 생겨요(보기 전용).
- **연습 데이터 항목별 지우기**: 설정 → 시뮬레이션의 각 항목 아래 "지우기" 버튼으로 그 종류만 지울 수 있어요.

## 경기모드

- 회원 화면 하단 메뉴 한가운데 ⚽ 버튼으로 들어가고, 한 번 더 누르면 홈으로 돌아와요.
- ① 대진 정하기: 1라운드 1경기, 2경기에 뛸 두 팀을 고르면 3경기와 2·3라운드(1라운드 반복)는 자동으로 정해져요. 경기마다 ⇄ 버튼으로 좌우를 바꿀 수 있어요.
- ② 경기 시간: 기본 전반 6분 + GK 교체 3초 + 후반 6분. ＋/− 로 바꿀 수 있어요.
- ③ 경기 화면: "경기 시작"을 누르면 3초 카운트다운 후 시작해요. 시작, 전반 종료, 후반 시작, 경기 종료 때 휘슬이 울려요. 골은 팀 아래 "+ 골"로 기록하고, 잘못 누르면 "− 골 취소"로 그 팀의 마지막 골을 지워요. 득점자는 기록하지 않아요. 경기 시작 카운트다운과 후반 시작 전(GK 교체 시간)에도 삐 소리가 나요. 끝난 경기는 아래 9경기 목록에서 눌러 점수를 고칠 수 있어요.
- 연습: 운영모드 → 설정 → 시뮬레이션에서 "경기모드"를 누르면 팀 구성까지 끝난 연습용 경기가 만들어져요.
- 진행자는 한 명이에요. 경기모드에 처음 들어온 사람이 진행을 맡고, 다른 회원은 보기 전용 화면(실시간 점수·시간)을 봐요. 휘슬도 진행자 폰에서만 울려요. "진행 넘기기"로 내려놓을 수 있고, 진행자 폰이 1분 넘게 응답이 없으면 다른 사람이 "진행 가져오기"를 할 수 있어요.
- 다른 메뉴로 가도 시간과 휘슬은 계속 이어져요. 휘슬은 소리 엔진의 시계에 미리 예약해 두어, 화면이 꺼져도 울리도록 했어요(안드로이드 크롬 기준. 아이폰은 화면이 잠기면 브라우저가 소리를 멈출 수 있어요).

## 경기 신청 안정성

- 신청 순서는 **신청이 서버에 도착한 시각**(서버가 직접 기록, 1/1000초 단위)으로 정해요. 폰 시계나 앱 조작으로 바꿀 수 없어요. 마감 시각 이후에 도착한 신청은 인정되지 않아요.
- 신청은 회원마다 작은 기록 1건으로 따로 저장돼서, 여러 명이 동시에 눌러도 서로 기다리지 않아요.
- 앱은 최근 90일 경기 기록만 실시간으로 불러오고(그 이전 경기는 경기결과에서 볼 때 불러옴), 한 번 받은 데이터는 폰에 저장해 다시 읽지 않아서 Firebase 무료 사용량을 크게 아껴요.
- 폰 시계가 틀려도 서버 시계 기준으로 신청 오픈·마감을 판단해요(5분마다, 앱으로 돌아올 때마다 다시 맞춰요).
- 신청 오픈 시각이 되면 새로고침 없이 바로 신청 버튼이 나타나요.
- 버튼을 여러 번 눌러도 신청은 한 번만 저장돼요. 저장 중에는 "신청 저장 중…"으로 버튼이 잠겨요.
- 신청은 서버에 "한 번에 추가"하는 단일 저장이라, 여러 명이 동시에 눌러도 서로 기다리지 않아요. 서버 응답이 9초 넘게 늦으면 버튼이 풀리고, 연결되는 대로 자동 저장돼요(멈춤 없음).
- Firebase 보안 규칙은 firestore.rules 내용으로 바꿔 두세요(테스트 모드는 30일 뒤 저장이 막혀요).

## 구장과 신청 순위

- 구장은 자주 쓰는 목록(용산 아이파크몰 The Base 1~7구장, 서울 월드컵경기장 풋살장 A~C면, 마루공원 풋살장 1·2면, 일원 에코파크 풋살장)에서 드롭다운으로 고르고, 목록에 없는 구장은 "✏️ 직접 입력…"을 고른 뒤 입력해요. 목록은 config.js의 venues로 바꿀 수 있어요.
- 0~3순위 규칙과 예약자·운영자 자동 신청은 **The Base 구장** 경기에만 적용돼요. 그 외 구장은 순위 없이 신청 순서대로(선착순) 선발해요.

## 간편 로그인

- 앱을 처음 열면 로그인 화면이 먼저 나와요. 자동 로그인을 켜 둔 기기는 바로 홈으로 들어가요. 운영진은 로그인 화면 아래 "운영모드로 들어가기"를 눌러요.

- 회원은 이름 + 숫자 4자리 비밀번호로 로그인해요. 처음 입력한 번호가 그대로 등록되고, 다른 기기에서도 같은 번호로 로그인하면 같은 회원으로 이어져요.
- "자동 로그인"을 켜 두면 그 기기(웹 브라우저, 홈 화면 앱 모두)에서 다음 접속 때도 로그인이 유지돼요.
- 신청 버튼을 누르면 순번이 먼저 확보되고, 로그인하지 않았으면 이름과 비밀번호를 입력해 신청을 확정해요.
- 비밀번호를 잊은 회원은 운영진이 회원관리의 "로그인 → 초기화"로 풀어 주면, 다음 로그인 때 새 번호를 등록해요.

## 진행 흐름

1. **신청**: 경기일을 만들 때 정원, 신청 오픈, 신청 마감 시간을 정해요. 회원이 "신청하기"를 누르는 순간 신청 순번이 먼저 확보되고, 이름은 그다음 입력해요(나중에 입력해도 순번 유지). 선발은 0순위(구장예약자·경기운영자, 정원과 무관하게 선발) → 1순위(직전 경기 미참여자) → 2순위(나머지 선착순) → 3순위(직전 경기에서 신청 마감 후 취소한 사람) 순서로 정원까지 채우고, 넘치면 신청 순서대로 대기가 돼요. 경기를 추가할 때(또는 경기관리 표의 "예약자 · 운영자" 칸에서) 구장 예약자와 경기 운영자를 지정하면, 따로 신청하지 않아도 0순위로 자동 신청돼요. 회원관리의 "운영진" 체크는 신청했을 때 0순위로 분류되는 표시예요. "신청 확정하고 주장 정하기"를 누르면 선발 명단이 드래프트 명단으로 확정돼요.
2. **주장**: 신청자 중에서 주장 3명을 고르고, 주장 링크(코드)를 보낸 뒤 "드래프트 방 열기".
3. **드래프트 방**: 위에는 신청자 명단 버튼, 가운데는 운영진과 주장 3명이 둘러앉은 드래프트 테이블, 맨 아래에는 항상 보이는 채팅 입력창이 있어요. 채팅은 모든 화면에서 같은 모양으로 맨 아래에 고정돼요(최근 대화 4~5줄 + 입력창 + 전체 내역 💬 + 나가기). 엔터키로 바로 보내지고, 테이블의 해당 자리 위에 말풍선으로 잠깐 떠요. 지난 대화는 "메시지 내역 보기"로 확인해요(안 읽은 메시지 수 표시). 진행 순서는 ① 운영진이 "색 선택 시작"을 누르면 주장들이 팀 색 선택(먼저 고른 팀이 그 색을 가져감, 색이 정해지기 전 팀 이름은 A팀/B팀/C팀) → ② 운영진이 순번 정하기 시작: "카드 뽑기"(주장들이 뒤집힌 카드 3장 중 한 장씩 골라 숫자가 작은 순서대로 순번 결정) 또는 "사다리 타기" → ③ 팀원 선택이에요. 색을 고르면 주장 카드 전체가 그 색으로 바뀌고(순번 정하기 전까지는 "색 다시 고르기"로 바꿀 수 있음), 뽑힌 팀원 이름도 팀 색으로 표시돼요. 자기 차례인 주장만 이름을 누를 수 있고, 운영진이 "다음 턴"을 눌러야 확정돼요.
4. **밸런스 조정**: 드래프트로 정해진 팀 구성 카드만 보여요. 채팅을 보내면 팀 카드 위에 말풍선으로 떠요. 팀 색 이름을 누르면(해당 팀 주장 또는 운영진) 다른 색으로 바꿀 수 있어요. 드래프트가 끝나면 각 팀 주장이 BLUE, BLACK, RED, WHITE, YELLOW, GREEN 중에서 조끼 색을 골라요(같은 색은 한 팀만). 운영진이 대신 골라도 돼요. 운영진은 선수 한 명을 누르고 다른 팀 선수를 누르면 맞바꿔요.
5. **공지**: 매치데이 이미지가 자동으로 만들어져요. 공유 버튼으로 카톡에 바로 보내거나 저장해요. NOTICE 문구에서 `{ }` 로 감싼 글자는 노란색이에요.
6. **경기**: 9경기 일정이 만들어지고, 전반 → GK 교체 → 후반 타이머와 휘슬, 골·도움, 순위, MOM이 기록돼요.

## 알아둘 점

- 운영진 비밀번호는 간단한 잠금이에요. 링크와 비밀번호를 외부에 공개하지 마세요.
