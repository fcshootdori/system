슛도리 앱
설치 방법

앱스토어에서 받을 필요 없어요. 브라우저에서 홈 화면에 설치하면 아이콘을 눌러 앱처럼 바로 열려요.

당신이 사용하는 브라우저를 선택해 주세요.

슛도리 앱 설치 방법

STEP 01 / 06

사파리를 열고 fcshootdori.github.io/system 로 접속합니다.

카톡에서 링크를 눌렀다면 꼭 사파리로 다시 열어 주세요.

STEP 02 / 06

주소표시줄의 아이콘을 누릅니다.

주소창 왼쪽에 있어요. 예전 iOS라면 화면 아래 공유 버튼 을 바로 눌러도 돼요.

STEP 03 / 06

공유 를 선택합니다.

STEP 04 / 06

더 보기를 선택합니다.

아이콘 줄 맨 오른쪽에 있어요.

STEP 05 / 06

홈 화면에 추가 를 선택합니다.

목록 아래쪽에 있어요. 안 보이면 위로 밀어 보세요.

STEP 06 / 06

오른쪽 위 추가 를 선택합니다.

"웹 앱으로 열기"는 켜 둔 그대로 두세요.

✓ 끝!

홈 화면에 생긴 슛도리 아이콘으로 열면 돼요.

이제 설치하러 가 볼까요?

아래 버튼으로 슛도리 앱을 열고, 방금 본 순서대로 사파리에서 홈 화면에 추가해 주세요.

앱 설치하러 가기 ›
  • 💬
    카톡에서 링크를 열었다면

    카톡 화면에서는 설치가 안 돼요. 오른쪽 아래 ⋯ → Safari로 열기를 누른 뒤 따라 해 주세요.

  • 🧭
    꼭 사파리에서

    아이폰은 사파리에서만 홈 화면에 추가할 수 있어요.

STEP 01 / 05

삼성인터넷 앱을 열고 fcshootdori.github.io/system 로 접속합니다.

STEP 02 / 05

주소표시줄의 아이콘을 누릅니다.

주소창 오른쪽 끝에 있어요.

STEP 03 / 05

"앱스 화면에 이 웹페이지를 추가할까요?"에서 추가 를 선택합니다.

STEP 04 / 05

세부정보 더보기 ⌄ 를 선택합니다.

"안전하지 않은 앱 차단됨" 창은 플레이 스토어를 거치지 않은 앱이라 뜨는 안내예요. 우리 팀 앱이니 걱정하지 마세요.

STEP 05 / 05

무시하고 설치하기 를 선택합니다.

✓ 끝!

홈 화면(앱스 화면)에 생긴 슛도리 아이콘으로 열면 돼요.

이제 설치하러 가 볼까요?

아래 버튼으로 슛도리 앱을 열고, 방금 본 순서대로 삼성인터넷에서 홈 화면에 추가해 주세요.

앱 설치하러 가기 ›
  • 💬
    카톡에서 링크를 열었다면

    오른쪽 위 메뉴에서 다른 브라우저로 열기 → 삼성인터넷을 고른 뒤 따라 해 주세요.

  • 🛡️
    "안전하지 않은 앱" 경고

    플레이 스토어를 거치지 않은 앱이라 뜨는 안내예요. 세부정보 더보기 → 무시하고 설치하기를 누르면 돼요.

STEP 01 / 05

Chrome 앱을 열고 fcshootdori.github.io/system 로 접속합니다.

STEP 02 / 05

주소표시줄 오른쪽 아이콘을 누릅니다.

STEP 03 / 05

설치 및 바로가기 만들기 를 선택합니다.

STEP 04 / 05

설치 › 를 선택합니다.

"바로가기 만들기"가 아니라 설치를 골라 주세요.

STEP 05 / 05

"앱 설치" 창에서 설치 를 선택합니다.

✓ 끝!

홈 화면에 생긴 슛도리 아이콘으로 열면 돼요.

이제 설치하러 가 볼까요?

아래 버튼으로 슛도리 앱을 열고, 방금 본 순서대로 크롬에서 홈 화면에 추가해 주세요.

앱 설치하러 가기 ›
  • 💬
    카톡에서 링크를 열었다면

    오른쪽 위 메뉴에서 다른 브라우저로 열기 → Chrome을 고른 뒤 따라 해 주세요.

  • 🔁
    설치 메뉴가 안 보이면

    이미 설치돼 있어요. 홈 화면이나 앱스 화면에서 슛도리 아이콘을 찾아보세요.
